# PHANTOM 架构与数据边界

## 实时决策链

1. 未修改的 DouZero 环境生成当前所有合法动作。
2. 三席 ADP 模型分别给合法动作评分，第一名作为基础动作。
3. 隐藏牌引擎只根据公开动作维护 512 个合法粒子，不读取对手真实手牌。
4. 二阶信念引擎分别估计两位对手会如何判断地主的王炸、炸弹与控制力。
5. 反事实模块只对基础模型前三个候选做历史分叉，不修改真实牌局。
6. 认知重排计算藏锋收益、诱导收益、未来控制价值和风险。
7. 基础价值损失超过 2% 的候选被硬否决；任何模块异常直接使用基础动作。
8. 动作、候选、来源、信念、状态机与指标同步写入前端事件和 JSONL 录像。

## 模式

- 核心演示与自动观战使用三席真实模型。
- 人机对战仅把地主动作改为本地玩家输入，合法动作仍由真实环境验证。
- 录像模式只读取已写入的事件，不重新推断，因此能够准确恢复当时的认知状态。
- MOCK 只用于视觉开发，并在界面持续显示“演示数据”。

## 行为画像边界

画像只保存出牌、过牌、炸弹、高牌早出和主动出牌等计数。第一局不参与在线决策，
完成一局后才以 0.75–1.25 的有限系数修正诱导收益。没有人格、心理或身份标签。

## 神经模型上线门槛

BeliefNet 在独立留出牌局上与解析条件概率基线比较。只有平均误差至少低 5% 才允许
进入融合。本次模型误差为 `0.10343658`，规则误差为 `0.09586673`，因此在线系统保留规则版本。

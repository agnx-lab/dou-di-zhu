# 《幻局斗地主》比赛演示脚本

## 一句话命题

这是一套可解释的斗地主辅助智能体：牌局只是验证环境，它把“为什么这样出”变成可检查的证据链。

## 90 秒推荐演示路径

### 0–12 秒：先让评委看懂

停留首页，先读出作品定位：“斗地主辅助智能体，而不是替玩家做决定的游戏”。指出三项价值：建议先过规则、原因可以检查、跨局逐步学习。最后说明实战牌桌只是验证这些能力的沙盘。

### 12–32 秒：进入真实牌局

点击“进入辅助体演示”。先指出左上角随机生成的六位牌局编号，再看三张可爱国风卡通头像、左右两名电脑玩家、中央桌面与底部玩家形成清晰三角关系。按住鼠标横向扫过五张牌，松开后一次完成选择，界面立即显示已选张数和具体牌型；再点击相邻牌，证明抬起牌不会遮挡操作。每次行动时，牌会从对应席位飞入中央，行动席发光，余牌数字和牌堆同步减少；评委无需读提示文字也能看懂是谁出了什么。

### 32–58 秒：展示 AI 不是装饰

点击“让 AI 帮我选”。右侧证据链会依次显示：检查了多少种合法走法、依据哪些公开行为判断局势、比较了哪些候选、最后把决定交还给玩家。强调 AI 不读取电脑暗牌，所有建议必须先通过斗地主规则校验。

紧接着指出“陪练 AI 成长”：进度会随本局选择即时增加；第二局开始，农民只在 DouZero 价值接近的安全候选之间，根据玩家的过牌、抢牌权和大牌使用习惯调整应对。

### 58–74 秒：证明规则完整

打开“完整规则”，快速指出三带一、三带二、顺子、连对、飞机、四带二、炸弹与王炸。回到牌局后展示上一手目标牌型与“组合非法 / 压不过”两类不同反馈。

### 74–90 秒：落到作品深度

展开“策略实验室”，展示隐藏牌信念、反事实候选与安全门。收束到作品命题：模型可以很强，但值得信任的辅助智能体必须可解释、受规则约束，并把最终决定留给人。

## 评委可能追问

- **是不是预设动画？** 不是。牌局由真实规则引擎推进，每个合法动作都由项目内 DouZero 权重评分；固定种子只用于可复现展示。
- **AI 有没有作弊？** 不读取两名电脑玩家的具体暗牌；隐藏牌判断只来自自己的手牌、公开出牌和剩余牌集合。
- **为什么没有叫分？** 当前作品聚焦最能体现策略推理的标准出牌阶段，玩家固定为地主；叫分与抢地主是明确保留的产品边界。
- **推荐一定正确吗？** 不承诺绝对正确。界面展示比较过程与安全限制，让玩家能理解、接受或拒绝建议。

## 演示前检查

使用 `启动完整演示.cmd` 启动，等待“幻局斗地主已就绪”，然后打开首页。正式展示前完成一局短测，确认声音、浏览器缩放和网络代理不会影响本地连接。
